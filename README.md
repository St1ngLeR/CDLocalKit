# Crashday Localization Toolkit
**CDLocalKit** is a utility for managing localization in Crashday (1.x/Redline). The program is a C# recreation of an internal tool used by the developers back in 2005.

This utility is not associated with Moonbyte Games or Replay Studios. This tool is a recreation with a large number of improvements.

## Features
- English and Russian language support
- Opening .plain files via file associations
- Drag'n'drop support
- Ability to merge multiple files (via drag'n'drop or a separate button)
- Exporting selected sections and keys
- Adding/removing sections and keys
- Search and replace by localization
- Search for untranslated strings
- Fully responsive program interface

## Hotkeys
- `Ctrl+N` - New .plain file
- `Ctrl+O` - Open .plain file
- `Ctrl+S` - Save .plain file
- `Ctrl+Shift+S` - Save .plain file as...
- `Ctrl+E` - Export selection
- `Ctrl+M` - Merge .plain files
- `Ctrl+F` - Find
- `Alt+F` - Find untranslated keys
- `Ctrl+R` - Replace
- `Ctrl+A` - Select/deselect all
- `Insert` - Add new section
- `Delete` - Delete selected sections
- `Shift+Insert` - Add new key
- `Shift+Delete` - Delete selected keys
- `F1` - About...
- `Alt+F4` - Exit
